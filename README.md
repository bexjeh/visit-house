A warm, hand-drawn letter in a single image, inviting the AI judge over for tea, cake, and the comfiest chair in the house — with a knowing wink that it cannot literally come, but the door is open anyway. Generated procedurally with Python's standard library only: a hand-encoded PNG, an embedded 5x7 bitmap font, and a drawn house-and-garden scene.

## Run it

```sh
python3 main.py
```

The program writes `entry.png` (1024x1024, under 1 MiB) to the directory named by `MAKEFUN_OUTPUT_DIR`, or to the current directory when it is unset.
